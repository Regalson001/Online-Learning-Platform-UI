# LearnPulse — Online Learning Platform UI

> A modern, responsive, and feature-rich online learning platform user interface built with HTML5, CSS3 (Tailwind CSS + Custom Glassmorphic Styling), and Vanilla JavaScript. Designed for high performance and a sleek developer portfolio showcase.

![Project Banner](https://images.unsplash.com/photo-1555066931-4365d14bab8c?auto=format&fit=crop&w=1200&q=80)

---

## 🚀 Key Features

* **Interactive Course Catalog:** Filter courses dynamically by category (*Web Development, Data Science, UI/UX Design, Cloud Architecture*) and difficulty levels (*Beginner, Intermediate, Advanced*).
* **Live Search Functionality:** Instant query filtering across course titles and descriptions.
* **Student Dashboard:** Tracks active enrollment metrics, study hours, learning streaks, and module completion progress bars.
* **Immersive Video Lesson Player:** Simulated interactive video player with custom controls, scrubbing timelines, play/pause states, and dynamic course curriculum sidebar tracking.
* **Modern Glassmorphism UI:** Built with dark-mode slate aesthetics, translucent panels, smooth hover micro-interactions, and custom scrollbars.

---

## 🛠️ Tech Stack

* **Markup:** HTML5 (Semantic Structure)
* **Styling:** Tailwind CSS (Utility classes) + Custom CSS (`styles.css` glassmorphic effects)
* **Icons & Fonts:** FontAwesome 6.4.0 & Plus Jakarta Sans (Google Fonts)
* **Interactivity:** Vanilla JavaScript (State management & View switching)
